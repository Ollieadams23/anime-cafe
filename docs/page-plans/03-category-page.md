# Category Page Plan (category.html)

## Page purpose
Show menu categories clearly so users can quickly browse what the cafe offers.

## Head and meta
- Title: Local Business Cafe | Categories
- Description: Browse cafe categories including coffee, drinks, and snacks.
- Include shared meta and links from site-wide guide.

## Required content blocks
1. Category intro
- Short explanation of how menu is grouped

2. Category cards
- Coffee
- Drinks
- Snacks
Each card should include:
- Category image/icon
- Short description
- Link/button to relevant section on products page

3. Optional category highlights
- Best seller in each category

## Links on this page
- index.html
- about.html
- products.html (with anchors if used)
- contact.html

## Suggested interactions
- Category card hover and focus states
- Optional JS filter preview

## Wireframe (simple)
+------------------------------------------------------+
| Header: Logo | Home About Category Products Contact |
+------------------------------------------------------+
| Category Intro: H1 + short text                      |
+------------------------------------------------------+
| [Coffee Card]  [Drinks Card]  [Snacks Card]          |
| each: image + text + button                          |
+------------------------------------------------------+
| Optional: Best Sellers by category                   |
+------------------------------------------------------+
| Footer                                                |
+------------------------------------------------------+

## Build checklist
- [ ] One clear H1
- [ ] 3 required categories present
- [ ] Each category has description
- [ ] Links to products work
- [ ] Mobile card layout remains readable
